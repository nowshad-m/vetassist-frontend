# VetPilot Frontend

A modern veterinary assistance application built with Next.js and Tailwind CSS.

<!-- Latest update: Added comprehensive API debugging and Test API functionality -->

## Features

- Modern, responsive UI design
- AI-powered veterinary recommendations
- Calendar-based dashboard
- Case management system
- Voice input capabilities
- Mobile-friendly interface

## Tech Stack

- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Vercel

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)
